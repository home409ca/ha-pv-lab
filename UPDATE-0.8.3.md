# PV Lab 0.8.3 — mapy paneli

Paczka zawiera wyłącznie zmiany względem 0.8.2. Wgraj zawartość do katalogu głównego repozytorium z zachowaniem podkatalogów i zaktualizuj aplikację. Nie usuwaj plików ani nie importuj historii ponownie.

Otwórz Panele i zacienienie. Początkowe mapy obu połaci są zgodne z numerowanym schematem. Wybierz Edytuj układ paneli: przeciągaj, obracaj lub zamieniaj przypisanie numerów, następnie Zapisz układ. Układ jest wspólny dla komputera i telefonu; nie zmienia prognozy ani kalibracji. Opcjonalne linie bazy domu i nadwyżki na wykresie prognoz pozostają domyślnie wyłączone.
